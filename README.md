# ec-fresh
Europa Clipper Flight Rule Evaluation Script Helper

## Installation

For a dev install:

`pip install .`

Or, for a packaged install:

`python3 setup.py sdist bdist_wheel`

`pip install dist/fresh-*.tar.gz`

To run:

`fresh -i [input .seq.json file]`

## Testing

`pip install -U pytest`

`python3 -m pytest test/`
